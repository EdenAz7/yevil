# אתר Lorem — הוראות התקנה

אתר סטטי בעברית (RTL), בנוי כמו iatransports.com: קבצי HTML + CSS + JS, בלי CMS ובלי שרת.
הלידים נשלחים ל-Google Sheets דרך Google Apps Script.
כל הטקסטים הם Lorem ipsum. רק תוויות פונקציונליות (תפריט, שדות טופס, כפתורים) בעברית.

## מבנה הקבצים

| קובץ | מה זה |
|---|---|
| `index.html` | דף הבית (hero, טאבים, שלבים, המלצות, אולם תצוגה, טופס, מאמרים, רשתות חברתיות) |
| `models.html` | קטלוג דגמים עם פילטרים, השוואת גדלים וטופס |
| `projects.html` | גלריית פרויקטים וטופס |
| `showroom.html` | אולם תצוגה: שעות, כתובת, Waze, טופס תיאום ביקור |
| `merci.html` | דף תודה אחרי שליחת טופס (מוגדר noindex) |
| `assets/js/config.js` | **כל ההגדרות במקום אחד**: כתובת הסקריפט, וואטסאפ, טלפון, רשתות, Waze |
| `assets/css/style.css` | העיצוב. צבעים ורדיוסים במשתנים בראש הקובץ (`:root`) |
| `assets/images/placeholder.svg` | תמונת ממלא מקום |
| `apps-script/leads.gs` | הקוד ל-Google Apps Script |

## שלב 1: גיליון ללידים
1. צרו Google Sheet חדש (השם חופשי).
2. תפריט **תוספים (Extensions) ← Apps Script**.

## שלב 2: הסקריפט
1. מחקו את הקוד הקיים והדביקו את התוכן של `apps-script/leads.gs`. שמרו.
2. (אופציונלי) ב-`NOTIFY_EMAIL` אפשר לשים מייל שיקבל התראה על כל ליד.
3. **Deploy ← New deployment ← סוג: Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
4. אשרו הרשאות (ייתכן מסך אזהרה של גוגל: Advanced ← Go to project).
5. העתיקו את כתובת ה-Web App (מסתיימת ב-`/exec`).
6. פתחו את `assets/js/config.js` והדביקו אותה ב-`SCRIPT_URL`.

בדיקה: פתיחת כתובת ה-`/exec` בדפדפן אמורה להחזיר `{"ok":true,"service":"leads"}`.
אחרי כל שינוי בקוד הסקריפט: **Deploy ← Manage deployments ← Edit ← New version**.

הסקריפט יוצר לבד לשונית `Leads` עם כותרות, וכותב שורה לכל ליד: תאריך, שם, טלפון, תחום עניין, הודעה, מועד מועדף, עמוד, הסכמה.
הוא גם חוסם בוטים (שדה מלכודת) ומגן מ"הזרקת נוסחאות" לגיליון.

## שלב 3: וואטסאפ, טלפון, רשתות
ב-`assets/js/config.js`:
- `WHATSAPP_NUMBER`: בפורמט בינלאומי בלי `+` ובלי מקפים. לדוגמה `972501234567`.
- `PHONE` ו-`PHONE_DISPLAY`: הטלפון להתקשרות והטקסט שמוצג.
- `SOCIAL`: הקישורים לאינסטגרם, פייסבוק וטיקטוק. כפתור הוואטסאפ הצף, כפתורי "וואטסאפ" והאייקונים בפוטר מתעדכנים לבד.
- `WAZE` ו-`MAPS`: קישורי ניווט לאולם התצוגה.

בדף הבית יש אזור "רשתות חברתיות" עם שלוש כרטיסיות. בכל אחת יש הערת HTML (`<!-- ... -->`) שמסמנת איפה להטמיע פיד אמיתי (ווידג'ט או iframe) במקום תמונות הממלא-מקום.

## שלב 4: תמונות, לוגו וטקסטים
- תמונות: כל התמונות הן `<img src="assets/images/placeholder.svg">`. החליפו את ה-`src` בתמונה אמיתית (מומלץ WebP או JPG בגודל סביר) או העלו קבצים לתיקיית `assets/images/`.
- לוגו: בכל דף יש `<span class="logo-mark">` ו-`LOGO` בהדר ובפוטר. מחליפים ב-`<img>` או בטקסט.
- טקסטים: מחליפים את ה-Lorem ipsum. כל דף הוא קובץ HTML רגיל.

## שלב 5: העלאה לאוויר
כל אירוח סטטי מתאים: GitHub Pages, Netlify, Cloudflare Pages או אחסון רגיל. מעלים את כל התיקייה (אפשר להשמיט את `apps-script/`).

## לפני העלייה
- להחליף את כל ה-placeholders: טלפון, מייל (`info@example.com`), כתובת, קישורי רשתות.
- לכתוב דפי מדיניות פרטיות, תנאי שימוש, נגישות ומחיקת מידע, ולקשר אליהם מהפוטר ומתיבת ההסכמה בטפסים.
- לאסוף הסכמה לעיבוד מידע אישי בהתאם לחוק. בטפסים יש תיבת סימון חובה לכך.
- לבדוק את הטפסים אחרי חיבור `SCRIPT_URL`: למלא ליד ולוודא שנוספה שורה לגיליון.
